# AGENTS.md — Календарь звонков (учебный проект Хекслета)

Сервис бронирования звонков: Ruby + Sinatra, хранение в памяти (`Store` + `Mutex`), ERB, vanilla JS.
API проектируется контрактом: `contract/main.tsp` (TypeSpec) → `openapi/openapi.yaml` (генерируется).
Требования и зафиксированные параметры (окно 14 дней, 09:00–18:00 Europe/Moscow, шаг 30 мин, 409 при пересечении) — в `README.md`.

## Команды

- `mise run install` — зависимости.
- `mise run check` — линт + тесты + сверка сгенерированного. **Задача не готова, пока `mise run check` не прошёл.**
- `mise run test` — только тесты; `mise run lint` — только линтеры; `mise run generate` — пересобрать OpenAPI.
- `mise run run` — сервер на http://localhost:4567.

## Правила

- Падение проверки печатает `rule N: …; fix: …` — исправляй ровно по `fix`, не обходи проверку.
- `openapi/` и `sdk/` генерируются (`.gitattributes`). Руками не править: меняй `contract/main.tsp`, затем `mise run generate`.
- Меняешь API → сначала контракт, потом код и тесты. Код должен отвечать ровно по контракту (коды 201/409/422).
- Исправляй причину, а не симптом: никаких `rescue nil`, пустых `rescue`, «значений по умолчанию» вместо ошибки.
- Тесты: minitest + rack-test, через HTTP-интерфейс приложения, без моков своего кода. Сначала тест, который падает, потом код.
- Ожидаемое значение в тесте берётся из требования (README), а не вычисляется проверяемым кодом.
- Не трогай `.github/workflows/hexlet-check.yml` — по нему Хекслет проверяет проект.
- Не меняй файлы, которых не касается задача. Чужие незакоммиченные изменения не трогай.
- Не делай `git push` и не коммить без просьбы. Сообщение коммита — по-русски, что и зачем.
- Застрял: одна и та же ошибка проверки дважды подряд → вызови субагента `advisor`, не перебирай варианты.
- Перед «готово» опиши: что изменено, какие команды запускал и их результат, что не проверено.
